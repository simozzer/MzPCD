**MzPCD for the Mac, as a beta.** MzPCD is the PCF's idea on a distortion, a pattern-controlled distortion, as a VST3 effect, and now an Audio Unit too.

![The MzPCD panel](https://raw.githubusercontent.com/simozzer/MzPCD/v0.2.0/docs/screenshot.png)

### What's new in 0.2.0
- **A macOS version (beta).** `MzPCD-0.2.0-macOS-beta.zip` has the VST3 and an **Audio Unit** for Logic and GarageBand. It runs on Apple Silicon and Intel Macs, macOS 11 or later.
- It's built and checked on GitHub's Macs, and passes Apple's own Audio Unit validator, but nobody has tried it on a real Mac yet. If something doesn't work, please [open an issue](https://github.com/simozzer/MzPCD/issues).

The sound is unchanged from 0.1.0, and so are the plugin's IDs. Projects saved with 0.1.0 load as before.

### Download

| File | What it is |
|---|---|
| `MzPCD-0.2.0-win64-Setup.exe` | **Windows: the installer.** Run it, then rescan plugins in your DAW. |
| `MzPCD-0.2.0-win64-VST3.zip` | Windows: the plugin, to install by hand. Copy `MzPCD.vst3` to `%LOCALAPPDATA%\Programs\Common\VST3` (or `C:\Program Files\Common Files\VST3`) and rescan in your DAW. |
| `MzPCD-0.2.0-macOS-beta.zip` | **macOS (beta):** the VST3 and the Audio Unit, with an install script. |

**Windows:** Windows 10 or 11, 64-bit. The installer and binaries aren't code-signed, so Windows may warn about an unknown publisher. Choose *More info → Run anyway*.

**macOS:** the download isn't signed by Apple, which takes a paid developer account, so macOS won't open it with a double-click. Unzip it, then in Terminal type `bash ` (with a space), drag `install.sh` from the unzipped folder into the window, and press Return. It copies everything into your own Library folders and clears the quarantine flag; then rescan plugins in your DAW. `READ ME FIRST.txt` in the zip explains how to install by hand instead.

### Known limitations
- **The Mac version is a beta**, untested on real hardware.
