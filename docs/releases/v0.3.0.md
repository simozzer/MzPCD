**MzPCD for Linux, as a beta.** MzPCD is the PCF's idea on a distortion, a pattern-controlled distortion, as a VST3 effect, an Audio Unit on the Mac, and now an LV2 on Linux too.

![The MzPCD panel](https://raw.githubusercontent.com/simozzer/MzPCD/v0.3.0/docs/screenshot.png)

### What's new in 0.3.0
- **A Linux version (beta).** `MzPCD-0.3.0-linux-x86_64-beta.tar.gz` has the VST3 and the LV2, for 64-bit x86 PCs on Ubuntu 22.04 or later, or another distribution as new. The **LV2** is for the hosts that load it best - Ardour, Carla, Qtractor, Zrythm - and the VST3 for Bitwig, Reaper and the rest.
- It is built and checked on GitHub's Ubuntu machines, and loads there, but has not been tried much in real Linux hosts yet. If something doesn't work, please [open an issue](https://github.com/simozzer/MzPCD/issues).

The sound is unchanged from 0.2.0, and so are the plugin's IDs. Projects saved with earlier versions load as before.

### Download

| File | What it is |
|---|---|
| `MzPCD-0.3.0-win64-Setup.exe` | **Windows: the installer.** Run it, then rescan plugins in your DAW. |
| `MzPCD-0.3.0-win64-VST3.zip` | Windows: the plugin, to install by hand. Copy `MzPCD.vst3` to `%LOCALAPPDATA%\Programs\Common\VST3` (or `C:\Program Files\Common Files\VST3`) and rescan in your DAW. |
| `MzPCD-0.3.0-macOS-beta.zip` | **macOS (beta):** the VST3 and the Audio Unit, with an install script. |
| `MzPCD-0.3.0-linux-x86_64-beta.tar.gz` | **Linux (beta):** the VST3 and the LV2, with an install script. |

**Windows:** Windows 10 or 11, 64-bit. The installer and binaries aren't code-signed, so Windows may warn about an unknown publisher. Choose *More info → Run anyway*.

**macOS:** the download isn't signed by Apple, which takes a paid developer account, so macOS won't open it with a double-click. Unzip it, then in Terminal type `bash ` (with a space), drag `install.sh` from the unzipped folder into the window, and press Return. It copies everything into your own Library folders and clears the quarantine flag; then rescan plugins in your DAW. `READ ME FIRST.txt` in the zip explains how to install by hand instead.

**Linux:** unpack the archive, then in a terminal in that folder run `bash install.sh`. It copies the plugins into `~/.vst3` and `~/.lv2`, with no password needed; then rescan plugins in your DAW. `READ ME FIRST.txt` in the archive explains how to install by hand, and lists the few libraries a minimal system might need.

### Known limitations
- **The Mac and Linux versions are betas**, not yet tried much on real hardware.
